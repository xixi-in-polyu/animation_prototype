# Reel Read and direction selection

Read this reference before modeling a substantial new animation. The Reel Read is a planning artifact, not part of `AnimationProject` schema version 5.

## Lightweight Reel Read

Write seven concise fields:

- `takeaway`: the one idea the audience should retain
- `hook`: the question, contrast, event, or image in the opening seconds
- `signature`: one memorable visual transformation or scene
- `benchmark`: a relevant communication or design reference and the specific principle to borrow; do not copy protected assets
- `forbidden`: project-specific failure modes to avoid
- `antiDefault`: the likely generic AI treatment and the composition, typography, and motion decisions that keep this work from becoming interchangeable
- `themeDecision`: the selected theme ID, the content signals that justify it, and the closest rejected candidate; use only the approved catalog in [light-theme-catalog.md](light-theme-catalog.md)

Keep factual claims traceable to supplied sources. A benchmark describes a method, not evidence for the subject matter.

## Separate format from style

Choose them independently:

- Format answers what the scene is doing: opening, explanation, process, comparison, incident, architecture, or closing.
- Style answers how the information looks and moves: editorial, diagrammatic, cinematic, interface-led, poster-like, restrained classroom visual, or another coherent system.

Do not use a style label as a substitute for scene purpose. Keep one dominant style system across the animation while varying scene formats to match the content.

## Three directions

For each direction, provide:

1. a short title;
2. format strategy and story spine;
3. visual style, palette, and motion character;
4. representative storyboard or style-frame description;
5. signature moment;
6. principal tradeoff.

The directions must differ in structure or visual language, not merely color. A useful set is:

- a source-faithful teaching direction;
- a story or incident-led direction;
- a bold conceptual direction.

When the user chooses, carry the decision into the full project. When the user requests a complete one-pass result, choose the direction that best preserves the source, fits the renderer vocabulary, and supports the takeaway. Record why it won and retain the other two directions so the decision is reversible.

Run the direction set through [aesthetic-defense.md](aesthetic-defense.md). A direction that depends on gradients, glows, cards, or palette to feel distinct is not yet a distinct direction.
