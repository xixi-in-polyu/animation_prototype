# Narration audio and captions

Use this reference whenever the skill creates or revises narration. The normal target is an editable project that already plays with TTS generated by the platform API; MP4 is a later platform export.

## Defaults and boundaries

- Default project, narration, TTS, and caption language to English unless the user specifies another language.
- Submit TTS content and caption-timing requirements to the platform API as part of normal production.
- Do not render local master or per-scene MP4 files for delivery or review.
- A future platform MP4 export should burn captions into the video by default. Preserve an SRT sidecar as an editable and accessible source.
- The LLM provides narration text, locale, a semantic voice profile, and delivery guidance. It does not hold provider credentials, call a vendor endpoint, or choose raw provider model or voice IDs.
- The platform resolves the semantic profile, performs synthesis, and returns provider, model, voice, locale, rate, measured duration, alignment, asset identity, and a bundle-relative URI.
- Default to the semantic profile `default-academic`. Provider-specific choices remain platform configuration and must be replaceable without rewriting the project.

## Platform request boundary

Submit one idempotent request for the affected scenes. A portable pending request may use this shape:

```json
{
  "version": 1,
  "projectId": "project-example",
  "projectRevision": "revision-id-or-content-hash",
  "voiceProfile": "default-academic",
  "locale": "en-US",
  "delivery": "calm, clear, professional",
  "scenes": [
    {
      "sceneId": "scene-opening",
      "segments": [
        {
          "segmentId": "scene-opening-n1",
          "text": "Narration text supplied by the LLM."
        }
      ]
    }
  ]
}
```

Use stable project, scene, and segment IDs. The platform owns credentials, provider selection, retries, rate limits, caching, retention, and licensing policy. Do not include an API key, vendor voice ID, absolute output path, or fabricated timing in the request.

If the platform TTS API is unavailable, deliver this as `tts-request.json` and set `ttsSynthesis.status` in `delivery-manifest.json` to `pending` or `unavailable`. Do not call Fish Audio or another provider directly as an unrecorded fallback. Without returned audio and timing, do not claim narrated playback, audio synchronization, completed captions, or readiness for MP4 export.

## Portable bundle

Keep paths relative to the delivered bundle. A typical bundle contains:

```text
project.animation.json
audio/
  scene-opening.wav
  scene-context.wav
tts-manifest.json
captions.srt
delivery-manifest.json
```

While synthesis is pending, `tts-request.json` replaces the absent audio and completed `tts-manifest.json`; it does not make the bundle narrated.

`tts-manifest.json` is a sidecar and does not change the canonical `AnimationProject` schema. It binds generated audio to stable project IDs:

```json
{
  "version": 1,
  "voice": {
    "provider": "available-provider",
    "voice": "available-english-voice",
    "locale": "en-US",
    "rate": 1
  },
  "scenes": [
    {
      "sceneId": "scene-opening",
      "assetId": "audio-scene-opening",
      "uri": "audio/scene-opening.wav",
      "duration": 31.572,
      "segments": [
        {
          "segmentId": "scene-opening-n1",
          "start": 0,
          "end": 5.4
        }
      ]
    }
  ]
}
```

Each `sceneId` and `segmentId` must exist in the project. Audio URIs must be portable relative paths. Record measured audio duration; do not substitute the requested or estimated duration. The scene must be long enough for its audio and intentional closing silence.

Generate SRT cues and project narration timing from the same timing data. Do not separately hand-author three timelines that can drift. When narration changes, regenerate the affected scene audio, its segment timing, captions, scene duration when necessary, and any narration-triggered motion cues; preserve unaffected audio and stable IDs.

`delivery-manifest.json` records export readiness without performing the export:

```json
{
  "version": 1,
  "ttsSynthesis": {
    "status": "complete",
    "requestId": "platform-request-id"
  },
  "videoExport": {
    "requested": false,
    "status": "not-requested",
    "burnCaptions": true,
    "captionSource": "captions.srt"
  }
}
```

Allowed TTS status values are `pending`, `running`, `complete`, `failed`, and `unavailable`. Only `complete` permits narrated-playback verification or MP4 readiness.

Allowed status values are `not-requested`, `ready-for-platform-export`, `export-requested`, and `export-unavailable`. Do not claim export readiness when required audio or caption files are missing.

## Review

Import the project bundle into Storyline Studio when the current product supports the bundle contract. Confirm that scene audio plays in order, narration-triggered motion remains aligned, captions match the spoken words, and the final narration leaves a deliberate closing beat. If the current product cannot consume the manifest, report that integration gap explicitly; the files may still be delivered, but narrated playback is not verified.
